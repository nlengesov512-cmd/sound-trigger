# Sound Trigger 2.0

## Возможности
- Мониторинг микрофона с живым индикатором уровня в относительных dBFS.
- Автоматическая WAV-запись при превышении настраиваемого порога.
- Завершение записи после заданного времени тишины (по умолчанию 13 секунд).
- Звуковой эпизод суммирует время звука; паузы до 8 секунд не сбрасывают его.
- После 14 секунд суммарного звука назначается будильник на выбранное время суток.
- Если выбранное время сегодня уже прошло, будильник переносится на следующий день.
- Настройки порога, тишины, допустимой паузы, длительности эпизода и времени будильника.
- Список записей с датой, длительностью, прослушиванием и системной отправкой.
- Файлы сохраняются в общедоступную папку Загрузки/SoundTrigger.

## Значения по умолчанию
- Порог: -40 dBFS (относительный).
- Тишина до остановки записи: 13 секунд.
- Допустимая пауза звукового эпизода: 8 секунд.
- Накопленное время звука до запуска будильника: 14 секунд.
- Время будильника: 08:00.

## Важные ограничения Android
- dBFS — относительный цифровой уровень, а не калиброванные акустические dB SPL.
- Для работы в фоне нужно выдать разрешение на микрофон и уведомления.
- Для максимально точного времени нужно разрешить приложению точные будильники в настройках Android. Без этого используется менее точный системный вариант.
- Производитель телефона может ограничивать фоновую работу; для стабильного мониторинга может потребоваться отключить оптимизацию батареи для приложения.
- Будильник выводится системным уведомлением со звуком и вибрацией; фактическое звучание зависит от системных настроек уведомлений и громкости будильника.

Минимальная версия Android — 10 (API 29).
