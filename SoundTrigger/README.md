# Sound Trigger (Android)

Минимальный Android-проект для автоматической записи по относительному уровню звука и запуска 10-минутного таймера.

## Логика

1. Нажать «Начать мониторинг» и выдать доступ к микрофону.
2. Приложение постоянно анализирует уровень микрофона в относительных dBFS.
3. Когда уровень достигает установленного порога, начинается WAV-запись.
4. Запись прекращается после 13 секунд подряд ниже порога (с гистерезисом 5 dB).
5. Если один и тот же фрагмент записи непрерывно длится 30 секунд, запускается таймер на 10 минут.
6. Если запись закончилась до 30 секунд, таймер не запускается.
7. После запуска таймер не отменяется из-за завершения записи. Его можно отменить кнопкой «Остановить мониторинг и таймер».

Таймер запускается максимум один раз за одну сессию мониторинга. Для новой попытки нужно остановить и снова запустить мониторинг.

## Важное о децибелах

Шкала dBFS относительная и зависит от микрофона, усиления и обработки звука конкретного телефона. Это не калиброванные акустические dB SPL. Настрой порог опытным путём в нужном помещении.

## Установка и сборка

1. Открой папку проекта в Android Studio (версия с поддержкой Android Gradle Plugin 8.7.3).
2. Дождись синхронизации Gradle.
3. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Установи APK на телефон.

Минимальная версия Android — 8.0 (API 26). Целевая версия сборки — Android 15 (API 35).

## Настройки телефона

- Разрешить доступ к микрофону.
- Разрешить уведомления.
- Нажать «Разрешить точный будильник» и предоставить специальный доступ, чтобы таймер срабатывал точнее.
- Для непрерывного мониторинга при выключенном экране исключить Sound Trigger из оптимизации батареи. Производители могут дополнительно ограничивать фоновые процессы.
- Звук будильника зависит от системной громкости будильника, разрешений уведомлений и режима «Не беспокоить».

Записи хранятся в app-specific каталоге Music/SoundTrigger. Кнопка «Поделиться последней записью» позволяет передать последний WAV-файл в другое приложение.
